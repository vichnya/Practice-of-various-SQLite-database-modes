# Practice of SQLite Database Modes

Учебный проект на Python, посвящённый работе с базами данных SQLite.

Проект развивался в несколько этапов: от работы с постоянной SQLite-базой до использования базы данных в памяти.

## Цель

На практике изучить работу с SQLite в Python, выполнение CRUD-операций, декораторы и различные варианты организации подключения к базе данных.

## Структура проекта

### `1. initial project - persistent_db`

Первая часть проекта посвящена работе с постоянной SQLite-базой данных.

В проекте реализованы:

* подключение к SQLite;
* создание и изменение таблиц;
* добавление, получение, изменение и удаление данных (CRUD);
* декораторы;
* логирование операций.

Проект развивался по версиям:

| Версия | Что изменилось                                                            |
| ------ | ------------------------------------------------------------------------- |
| `v.1`  | Базовая работа с постоянной SQLite-базой: подключение, CRUD и логирование |
| `v.2`  | Добавлена настройка уровня логирования                                    |
| `v.3`  | Уровень логирования передаётся непосредственно в декоратор                |

### `2. continuation of the project - in_memory_db`

Продолжение проекта, посвящённое работе с SQLite-базой данных в памяти (`:memory:`).

В проекте дополнительно реализован класс `User` для работы с объектами пользователей.

Проект развивался по версиям:

| Версия | Что изменилось                                                                       |
| ------ | ------------------------------------------------------------------------------------ |
| `v.1`  | Переход на SQLite-базу в памяти и работа с классом `User`                            |
| `v.2`  | Подключение к БД вынесено в отдельный класс `Connection`, добавлен паттерн Singleton |

## Технологии

* Python
* SQLite
* `sqlite3`
* SQL

## Результат

Проект позволил на практике изучить взаимодействие Python-приложения с SQLite, выполнение CRUD-операций, применение декораторов и паттерна Singleton, а также различия между постоянным хранением данных и использованием базы данных в памяти.
