# Practice of SQLite Database Modes

Учебный проект на Python, посвящённый работе с базами данных SQLite.

Проект развивался в несколько этапов: от работы с постоянной SQLite-базой до использования базы данных в памяти.

## Цель

На практике изучить работу с SQLite в Python и различные варианты организации подключения к базе данных.

## Структура проекта

### `1. initial project - persistent_db`

Первая часть проекта посвящена работе с постоянной SQLite-базой данных.

В процессе разработки реализованы:

* подключение к SQLite;
* создание и изменение таблиц;
* добавление, получение, изменение и удаление данных;
* использование декораторов для работы с подключением;
* логирование операций.

Проект развивался по версиям `v.1`, `v.2`, `v.3` и далее.

### `2. continuation of the project - in_memory_db`

Продолжение проекта, посвящённое работе с SQLite-базой данных в памяти.

Реализация также выполнялась поэтапно в нескольких версиях.

## Технологии

* Python
* SQLite
* `sqlite3`
* SQL
* Poetry

## Результат

Проект позволил на практике изучить взаимодействие Python-приложения с SQLite, выполнение SQL-запросов и различия между постоянным хранением данных и использованием базы данных в памяти.
